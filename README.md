# mdv

Консольный просмотрщик Markdown, написанный на C. Цветные заголовки, списки,
таблицы, цитаты, ссылки и подсветка кода. Длинные документы открываются в `less`
с прокруткой и поиском.

```sh
mdv README.md
```

Один исполняемый файл. Python и другие языковые среды для работы не нужны.

## Сборка и установка

Нужны компилятор C11, `make` и POSIX-система (Linux/macOS).
Для прокрутки установите `less`. Без него документ выводится прямо в терминал.
Поддержка ANSI и локаль UTF-8 нужны для корректного отображения цвета и Unicode.
Проверено на Linux с Fish.

Скачайте или клонируйте репозиторий, перейдите в его каталог:

```sh
make
./mdv example.md
sudo make install
```

По умолчанию команда устанавливается в `/usr/local/bin/mdv`.
Установка без прав администратора:

```sh
make install PREFIX="$HOME/.local"
```

В этом случае добавьте `~/.local/bin` в `PATH`. Для Fish:

```fish
fish_add_path ~/.local/bin
```

Парсер [MD4C 0.5.2](https://github.com/mity/md4c/tree/release-0.5.2)
включён в исходники: скачивать зависимости при сборке не требуется.

## Алиас md

Установка создаёт только команду `mdv`, чтобы не занимать короткое имя `md`.
Если хотите пользоваться `md test.md`, добавьте алиас.

Fish — выполните один раз:

```fish
alias --save md='mdv'
```

Bash/Zsh — добавьте в `~/.bashrc` или `~/.zshrc`:

```sh
alias md='mdv'
```

Алиас вызывает `mdv` с теми же аргументами. При конфликте имени удалите алиас
и продолжайте использовать `mdv`. В Fish для удаления сохранённого алиаса
удалите `~/.config/fish/functions/md.fish`, затем выполните `functions --erase md`.

## Использование

```sh
mdv test.md
mdv "Мой документ.md"
mdv --theme light test.md
mdv --no-pager test.md
mdv --no-color test.md
mdv --width 80 test.md
cat test.md | mdv
mdv - < test.md
mdv --help
mdv --version
```

| Параметр | Назначение |
| --- | --- |
| `--theme dark` / `--theme light` | Тема терминала, по умолчанию `dark` |
| `--no-pager` | Вывод без просмотрщика |
| `--no-color` | Отключить цвет и оформление ANSI |
| `-w N`, `--width N` | Ширина текста: от 20 до 10000 колонок |
| `--help` | Справка |
| `--version` | Версия |

По умолчанию ширина — до 100 колонок, с учётом размера терминала.
Длинные строки переносятся; ширина учитывает кириллицу, широкие символы
и комбинируемые знаки. Таблицы переносят содержимое внутри ячеек;
если столбцы не помещаются, ячейки выводятся последовательно по строкам.

Переменная окружения `NO_COLOR` отключает оформление ANSI.
При перенаправлении вывода цвет и просмотрщик отключаются автоматически.
Без имени файла программа читает stdin, а при запуске без аргументов
в терминале показывает справку.

В `less`:

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓`, `PgUp` / `PgDn` | Прокрутка |
| `/текст` и Enter | Поиск |
| `n` / `N` | Следующее / предыдущее совпадение |
| `q` | Выход |

Короткие документы остаются в терминале без ожидания выхода.
Пример оформления: [`example.md`](example.md).

## Поддержка Markdown

Парсер обрабатывает CommonMark, таблицы, зачёркивание и списки задач.
Поддерживаются вложенные списки, цитаты, ссылки, HTML-сущности,
блоки кода и встроенный код.

Файлы должны быть в UTF-8, допускается BOM. Изображения отображаются
как подписи; HTML — как исходный текст. Формулы LaTeX и диаграммы Mermaid
не рендерятся. Подсветка кода базовая: строки, комментарии, числа и
распространённые ключевые слова для C-подобных языков, Python, оболочек,
Ruby, YAML, TOML и JSON. Это не полный синтаксический анализ языков.
Вложенность Markdown ограничена 128 уровнями.

## Проверка

```sh
make test
```

Тесты написаны на POSIX shell. Проверяют параметры CLI, чтение stdin,
UTF-8/BOM, ошибки файлов, списки, таблицы, ссылки, вложенность и управляющие
символы. Для дополнительной проверки памяти можно собрать с санитайзерами:

```sh
make clean
make CFLAGS='-O1 -g -std=c11 -Wall -Wextra -Wpedantic -fsanitize=address,undefined' \
     LDFLAGS='-fsanitize=address,undefined'
make test
```

Исходники программы — `src/mdv.c`, парсер — `vendor/md4c/`.
Подробности происхождения стороннего кода — в [`vendor/md4c/README.md`](vendor/md4c/README.md).
Сборка не использует сеть. `.gitignore` исключает бинарник и временные файлы.

Удаление установленной команды:

```sh
sudo make uninstall
```

Для пользовательской установки: `make uninstall PREFIX="$HOME/.local"`.
Алиасы удаляются отдельно.
